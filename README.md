# humanette

Humanette helps make browser automation videos easier to understand. Add it to your project and you'll get Screen Studio style large cursors and keyboard presses that look like a user using your product.

- Agents can make more understandable videos of themselves using browsers
  - To show a new feature they built
  - To prove they tested their work
- videos can record easier to understand videos of using a browser
- Generate beautiful product walkthrough videos
